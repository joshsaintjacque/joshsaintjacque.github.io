Write posts in this folder. Set `draft: true` until you are ready to publish; Quartz excludes drafts from the built site.

Run sync and build from the blog repo:

```bash
cd ~/workspace/blog
npm run sync
npx quartz build --serve
```

Then commit and push to deploy.
